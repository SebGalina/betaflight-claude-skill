# Setup Wizard — Initial Drone Configuration

This wizard is triggered **only on explicit user request** (see triggers in SKILL.md). It guides the user from zero to an applied or exported baseline configuration.

## Step 1 — Collect build info

Ask all questions **at once**, in a single grouped message:

| Info | Examples |
|------|----------|
| Frame type and size | 3" cinewhoop, 5" freestyle, 7" longrange, tinywhoop… |
| Motors (KV) | 2306 2450KV, 1404 3800KV… |
| Prop size | 5×4.3×3, 3×2×3… |
| Battery (S) | 3S, 4S, 6S |
| ESC protocol | DSHOT300, DSHOT600 — if unknown, default to DSHOT300 |
| Receiver protocol | ELRS, CRSF, SBUS, FPort, iBUS… |
| Flying style | Freestyle, racing, cinematic, longrange |
| Experience level | Beginner, intermediate, experienced |

Do not re-ask anything the user already provided in their initial message.

## Step 2 — FC connection (optional)

Ask whether the FC is plugged in via USB:

- **Yes** → `list_serial_ports` → propose the detected port → `connect` → `get_board_info` to confirm firmware version.
- **No / MCP unavailable** → offline mode: generate a CLI diff to paste into Betaflight Configurator.

If `connect` fails: automatically fall back to offline mode without blocking.

## Step 3 — Load preset

Select from `assets/presets/`:

| Build | Preset |
|-------|--------|
| 3" cinewhoop / nano | `cinewhoop-3inch.txt` |
| 5" freestyle / racing | `5inch-freestyle.txt` |
| 7" / longrange | `longrange-7inch.txt` |

If no preset matches exactly, use the closest one and say so.

## Step 4 — Apply or export

**Connected mode (MCP available):**

1. Read current state: `get_pid_values`, `get_rates`, `get_filter_config`
2. Calculate target values from preset + build info
3. Present change summary and ask for explicit confirmation
4. Apply: `set_pid_values` (roll, pitch, yaw) + `set_rates`
5. `save_config` → warn user that the FC will reboot

**Offline mode:**

```
# Baseline tune — [build type] — generated by Betaflight Assistant
# Betaflight [version] · [date]
set pid_roll_p = ...
set pid_roll_i = ...
...
save
```

## Rules

- Never call `save_config` without explicit user confirmation.
- Always remind the user to remove props before any motor test.
- If a calculated value falls outside the safe ranges in `references/parameters.md`, flag it and ask for confirmation.
- The wizard produces a **starting configuration**, not a final tune. Always finish by recommending a test flight and progressive PID adjustment.
